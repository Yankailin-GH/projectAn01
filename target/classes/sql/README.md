# SQL 文件说明

## 文件结构

所有 SQL 文件统一存放在 `resources/sql` 文件夹下。

### init.sql
- **用途**: 数据库初始化脚本（完整版）
- **包含内容**:
  - 数据库创建
  - 所有表结构定义（sys_users, sys_roles, sys_menus, sys_user_roles, sys_role_menus, categories, products）
  - 初始化数据（系统角色、菜单、分类、示例商品）
  - 角色权限关联
- **执行方式**: 首次初始化数据库时执行此脚本
- **生成日期**: 2026-03-16

## 使用说明

1. **首次初始化**: 直接执行 `init.sql` 即可完成数据库和数据的初始化
2. **后续维护**: 新增的 SQL 脚本应放在此文件夹下，并按功能分类命名
3. **版本控制**: 所有 SQL 文件都应纳入版本控制

## 注意事项

- 所有 SQL 文件使用 UTF-8 编码
- 数据库字符集为 utf8mb4
- 使用 InnoDB 存储引擎
- 支持 MySQL 8.0+
